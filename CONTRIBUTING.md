# Contributing to Steam Freebie Bot

Thank you for your interest in improving the Steam Freebie Bot! We welcome all contributions from the community.

## How Can I Contribute?

### 🐛 Reporting Bugs
* Check the **Issues** tab to see if the bug has already been reported.
* If it hasn't, open a new issue. Include a clear description of the problem, what you expected to happen, and steps to reproduce it (or logs from GitHub Actions).

### 💡 Suggesting Enhancements
* Open an issue outlining your feature request.
* Explain why this feature would be useful to other users.

### 🛠️ Submitting Code Changes (Pull Requests)
1. Fork the repository to your own account.
2. Create a new branch for your feature or bug fix (`git checkout -b feature/amazing-feature`).
3. Make your changes and ensure your Python script runs cleanly.
4. Commit your changes with clear descriptions.
5. Push to your branch and open a **Pull Request** against our `main` branch.

## Code of Conduct
Please note that this project is released with a [Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project, you agree to abide by its terms.
